Therefore, 「能量核心」 emphasizes its essential role as the central component of the energy network, rather than simply describing it as a device that regulates energy.

This translation is based on the functionality and terminology documented by the original developers.

Gold Ingot (24-Carat) → 純金 (24克拉)

I chose 「純金」 (Pure Gold) to distinguish the final stage of gold refinement from the lower-purity gold ingots.

Over my five years of playing Slimefun, I've found that obtaining 24-carat gold often involves a lengthy and repetitive refinement process. Since it is also an essential material for crafting Reinforced Alloy Ingots, reaching this stage has always felt like a meaningful milestone.

While the lower-purity variants retain the name 「金錠」 (Gold Ingot), giving the final 24-carat variant the distinct name 「純金」 provides a stronger sense of progression and accomplishment.

This intentional naming difference serves as a subtle reward for completing the refinement process. Rather than simply increasing the carat number, it gives players a small but satisfying sense of achievement when they finally obtain the material.

Furthermore, since 24-carat gold is commonly associated with pure gold, this translation remains consistent with the material's intended purity.

Gold Block (24-Carat) → 純金磚 (24克拉)

Same reasoning as Gold Ingot (24-Carat). This translation maintains naming consistency with 「純金」 (Pure Gold) while distinguishing the block form.


GPS Activation Device (Personal) → GPS 傳送板 (私人)

I chose 「GPS 傳送板」 (GPS Teleportation Pad) based on both the device's actual functionality and the terminology used in Slimefun4's official source code.

In the official implementation, this device is represented by the class `PersonalActivationPlate`, which extends `AbstractTeleporterPlate`. The official Javadoc explicitly describes it as a teleporter activation plate.

Players stand on this plate to access the teleportation menu and select their destination. Therefore, 「傳送板」 more accurately conveys its physical form and practical purpose than the generic term 「啟動裝置」 (Activation Device).

Although it requires the complete GPS teleportation structure to function, the proposed translation helps players immediately recognize its role in the teleportation system.

## 通用介面

> 工具位於 `D:\SF5-Translation\dictionary.cjs`，支援 JavaScript API 與 CLI JSON stdin/stdout。詞表可以用 `dictionaryPath`／`--dict` 指定，不綁定 SF5。
> JavaScript 範例：

```javascript
const { createTranslator } = require('D:/SF5-Translation/dictionary.cjs');
const translator = createTranslator({
  dictionaryPath: 'C:/Users/Owner/.codex/worktrees/cee9/OB-SF/@繁簡詞對照.md'
});
const text = translator.convert('电池和背包');
const texts = translator.convertMany(['电池', '電池']);
const report = translator.convertWithReport('工作台');
// report.text、report.matches；translator.metadata 含詞表 SHA256。
```

> CLI 可呼叫 `node D:/SF5-Translation/dictionary.cjs --json --dict 詞表路徑`，stdin 傳入 `{"texts":["电池","電池"]}`，stdout 回傳 `{"texts":[...],"dictionary":{...}}`。錯誤寫入 stderr 並回傳非零退出碼。
> `--check` 只驗證詞表，`--text` 轉換單一文字；`--input`／`--output` 可處理純文字檔，輸出不得覆寫既有檔案。處理 YAML 請使用 SF5 轉換模組，只轉文字值，勿直接整檔套用純文字介面。
> 目前為介面與詞表格式實作完成，尚待使用者執行測試；EXAMPLE 不代表已核定專案用語。
